##Overview
The Network Track focuses on understanding the networking concepts and technologies required for communication between devices and systems. In the NAFATH-V3 project, networking plays an important role in enabling the mobile application to connect to servers, exchange data, and provide users with digital services. This track explores how data is transmitted over networks using protocols such as TCP/IP and HTTPS, which help ensure reliable and secure communication. It also highlights the importance of network security, encryption, and authentication in protecting sensitive information from unauthorized access. In addition, the track examines how network performance, connectivity, and server availability affect the application's functionality and user experience. Overall, the Network Track provides an understanding of how secure and efficient network communication supports the operation of modern mobile applications and helps maintain the confidentiality, integrity, and availability of user data.

## Software — Semantic Versioning
Semantic Versioning uses three numbers: MAJOR.MINOR.PATCH. The MAJOR version increases when a change to the public API is not backward-compatible and may require users to change their code. The MINOR version increases when new, backward-compatible functionality is added or public functionality is deprecated. The PATCH version increases when backward-compatible bug fixes are made without changing the public API.
Resource:<https://semver.org/spec/v2.0.0.html>

## AI — Retrieval-Augmented Generation (RAG)
Retrieval-Augmented Generation (RAG) is a technique that retrieves relevant information from external sources before an AI model generates an answer. This helps ground the answer in existing information instead of relying only on the model's training. RAG can reduce hallucinations by providing valid information, such as real workflow steps or database table names, but it cannot guarantee that every answer will be correct.
Resource: <https://aclanthology.org/2024.naacl-industry.19/>

## Mobile — App Transport Security (ATS)
App Transport Security (ATS) is an Apple security feature that requires iOS apps to use secure network connections that meet Apple's requirements. It encourages HTTPS, which encrypts data sent between an app and a server. When an app tries to connect to a plain HTTP endpoint, ATS normally blocks the connection unless the developer configures an exception. This helps protect data from interception during transmission.
Resource: <https://developer.apple.com/documentation/security/preventing_insecure_network_connections>

## Networking — IPv4 and IPv6
IPv4 uses 32-bit addresses, while IPv6 uses 128-bit addresses. IPv6 therefore provides a much larger number of possible addresses than IPv4. This difference matters because more phones, computers, and other connected devices need unique network addresses as the internet grows. IPv6 helps address the limited supply of IPv4 addresses and supports the increasing number of connected devices.
Resource: <https://www.rfc-editor.org/rfc/rfc8200>
